# LLM-wiki

Daily research wiki for OpenCode. Follows the Karpathy LLM-Wiki three-layer pattern.

- **Finance** (金融) — investing, markets, personal finance
- **Product** (产品) — product management, design, case studies
- **Daily Life** (生活) — health, travel, productivity, culture

**Layout:** `inbox/` → `sources/` → `concepts/` + `entities/` → `synthesis/`

Start at [`index.md`](index.md) for the catalog.
See [`AGENTS.md`](AGENTS.md) for agent workflows.

# AI 使人乏味（AI Makes You Boring）

## 核心论点

Marginalia Search 创始人 Viktor Löfgren 在 2026 年 2 月提出的一个文化批评：

> **AI 使人乏味。** 不是因为 AI 本身不好，而是因为用 AI 替代思考过程会系统性地扼杀原创性。

## 论证链条

### 1. 原创来自沉浸，而非外包

人类产生原创想法的方式是**长时间沉浸在一个问题中**。这个过程没法被跳过：

```
沉浸于问题 → 反复试错 → 意外发现 → 打磨表达 → 原创想法
```

用 LLM 完成这个过程的任何一步，都会得到"浅层的、表面化的"想法，而非真正原创的洞察。

### 2. "人在回路中"是一个陷阱

常见反驳："AI 只是工具，人在回路中做高层决策就够了。"

但 Löfgren 认为这个前提是错的——**原创想法恰恰来自于你外包给 LLM 的那个劳动过程。**"人在回路中"并不会让 AI 思考得更像人，反而会让人的思考变得更像 AI 的输出。

> 你用挖掘机举重是练不出肌肉的。你用 GPU 来思考是产生不了有趣想法的。

### 3. 表达即思考

想法在你试图表达它的时候得到进一步打磨。这就是写作、教学、讨论的价值——它们迫使你把模糊的直觉变成清晰的表述。

而**给 AI 写提示词不是表达想法**。你得到了输出，但就构思而言，输出是可以丢弃的。真正重要的是那个劳动过程。

### 4. AI 前时代的独特价值

Löfgren 回忆 AI 之前的 Show HN：

> 最酷的地方在于你能和一个**比你思考一个问题更久的人**交流。那是真正学到新东西、获得完全不同的视角的机会。

AI 时代的 Show HN 则相反——作者没有深入思考问题空间，项目乏味，讨论浅薄。

## 适用范围

| 场景            | AI 辅助是否合适 | 原因           |
| ------------- | --------- | ------------ |
| 探索不熟悉的领域      | ✅ 合适      | 快速获取框架性知识    |
| 写博客/设计产品/原创工作 | ❌ 致命缺陷    | 系统性地破坏原创性    |
| 处理已知模式的重复任务   | ✅ 合适      | 解放精力做更高层次的思考 |
| 需要深度洞察的讨论     | ❌ 不合适     | 产出浅层、表面化内容   |
| 学习/入门阶段       | ✅ 有益      | 降低门槛，快速起步    |
| 大师级创作         | ❌ 有害      | 跳过沉浸过程，失去打磨  |
|               |           |              |

## 相关的思想脉络

- **表达即思考**：写作不是思想的"记录"，而是思想的"生成"过程。这一点在 George Orwell、Joan Didion 等作家那里都有深刻论述
- **效率悖论**：试图跳过艰苦思考过程来"提高效率"，反而得到了更低质量的结果
- **工具的辩证**：Löfgren 并不反对 AI 工具本身（"工具就是工具"），但反对将工具用在不该用的地方——这本质上是对**工具理性**的批判
- **Feynman 方法**：Richard Feynman 以"真正理解一个问题"为核心理念——不是靠记忆答案，而是靠从头推导。

## 在相关文献中的位置

Löfgren 的文章是 2025–2026 年 AI 文化批评潮流的一部分，与以下观点形成互文：

- Cal Newport 的"深度工作"（Deep Work）理论——碎片化地使用 AI 与碎片化的注意力一样有害
- 程序员社区对"vibe coding"的反思——生成大量代码却不理解其含义
- 教育领域对"AI 代写"的担忧——跳过写作过程 = 跳过思考过程

# AI 创业同人小说

> 源：[[sources/阅读/LinkedIn同人小说]] — Marginalia 博客（Viktor Löfgren, 2026）

## 概述

对 LinkedIn/AI 创业圈"成功学幻想故事"的完整讽刺。作者用 AI 编年史叙事风格写了一个假故事——主角用 AI 在公交车上"用代码解决社会问题"——以达到真实的讽刺效果。

> 这个"概念"的标题本身就是讽刺。

## 讽刺的对象

### 被解构的套路

| 套路模板         | 本文中的对应                                         |
| ------------ | ---------------------------------------------- |
| 在公共场合遇到小问题   | 小混混骚扰老太太                                       |
| AI 开发者立刻动手   | Claude 自动写代码（`--dangerously-skip-permissions`） |
| AI 瞬间完成      | 部署到 localhost:8080/"黑进手机"                      |
| AI 信息图"教育"对方 | 吉卜力风格 AI 信息图教育他们要关注 MRR                        |
| 对方立刻醒悟并崇拜    | 混混们"哦天哪，我们完蛋了！"                                |
| 卖课           | 1400 美元的"用 AI 打造骚扰老太太的帝国"课程                    |
| 全场鼓掌         | 公交车上响起掌声                                       |
| 行业大佬认可       | John Carmack "他笑着说自己只是 10X，不是 100X"            |
| 终极反转/被大佬奖励   | 公交车是游艇，老太太是 Bezos，Bill Gates 是司机               |

### 被嘲讽的具体对象

- **LinkedIn 创业叙事文体**（hustle culture / "the grind"）
- **AI 开发者万能论**（"Claude 在我想好之前就写完了代码"）
- **`--dangerously-skip-permissions`**（Claude Code 的真实 flag，讽刺安全意识的缺失）
- **MRR/IPO 崇拜**（Dario、Cybertruck、Dario——重复"达里奥"强调圈子内的自我重复）
- **AI 拯救世界叙事**（用 AI 信息图就能让人顿悟）
- **卖课变现**（任何故事最终都导向课程销售）
- **大佬见证**（John Carmack / Bill Gates / Jeff Bezos / Elon Musk / Sam Altman——硅谷名人全明星串场）

## 写作手法

- 身份悬疑（老太太/Bezos；公交车/游艇；混混/Musk + Altman）
- 名字重复制造荒诞感（"Dario and Cybertrucks and Dario"）
- 自我揭穿（结尾直接把所有反转点破）

# 学习新事物的心理模型

> 源：[[sources/阅读/你应该学点东西]] — Marginalia 博客（Viktor Löfgren, 2026）

## 核心论点

学习新技能本质上是心理上痛苦的，但这种痛苦是正常的、暂时的、可预期的。关键在于**管理预期**——知道"感觉糟糕"本就是过程的一部分，就不会轻易放弃。

## 学习曲线模型

1. **恐怖之山（Mt. Awful）** — 刚开始时感觉极差，越练越糟，大脑和肌肉疲劳。大多数人此时放弃。
2. **飞跃** — 如果第二天继续，会发现事情已明显变容易（因为睡眠期间大脑处理了白天的练习数据）。
3. **对数平台期（平庸中级）** — 进步放缓，停在"能用但不出色"的阶段。大多数人走不到这一步。
4. **跨越平台期** — 通过日常附带练习（incidental practice）继续进步，无需刻意苦练。如何做到超出本文范围。

## 关键原则

| 原则 | 说明 |
|------|------|
| 练习 ≠ 进步 | 练习是收集数据，睡眠才是进步发生的时刻 |
| 越练越差是正常的 | 结束时表现下降是疲劳的体现，不是退步 |
| 每天 30-45 分钟 | 超出此时间只会疲劳固化错误 |
| 以错误为信号 | 当开始频繁犯错，就是停下的好时机 |
| 专注基础 | 练习还没准备好的高级内容没用，刷高级讨论也没用 |
| 长期项目 | 学习是数月到数年的事，不是一天的事 |

## 适用范围

适用于**身体/技能类学习**（乐器、运动、盲打、建模等）需要反复刻意练习的领域。对于纯知识类学习（读书、听课）参考价值部分适用。

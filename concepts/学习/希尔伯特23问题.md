# 希尔伯特 23 个数学问题

> 源：[[sources/学习/希尔伯特23问题]] — 希尔伯特 1900 年 ICM 巴黎演讲

## 23 个问题一览

| # | 问题 | 解决状况 |
|---|------|------|
| 1 | 连续统假设（Continuum Hypothesis） | 不可判定于 ZFC（Cohen 1963） |
| 2 | 算术公理的相容性 | 哥德尔不完备定理（1931） |
| 3 | 等体积四面体的全等问题 | 否定解决（Dehn 1900） |
| 4 | 直线为最短距离问题 | 部分解决 |
| 5 | 连续群是否必为李群 | 解决（Gleason-Montgomery-Zippin 1952） |
| 6 | 物理学的公理化 | 部分解决（见 [[concepts/学习/希尔伯特第六问题]]） |
| 7 | 某些数的超越性 | 解决（Gelfond-Schneider 1934） |
| 8 | 黎曼猜想 | **未解决**（见 [[concepts/学习/黎曼猜想]]） |
| 9 | 一般互反律 | 部分解决（类域论） |
| 10 | 丢番图方程的可判定性 | 否定解决（Matiyasevich 1970） |
| 11 | 代数数域上的二次型 | 部分解决 |
| 12 | 克罗内克青春之梦 | 部分解决 |
| 13 | 七次方程能否用两变量函数解 | 解决（Kolmogorov-Arnold 1957） |
| 14 | 某些函数系的有限生成性 | 否定解决（Nagata 1959） |
| 15 | 舒伯特枚举几何 | 部分解决 |

| 18 | 空间填充/开普勒猜想 | 部分解决（Hales 1998） |
| 19 | 变分问题解的正则性 | 解决（Bernstein 等） |

## 重要性排名

### Tier 1：动摇了数学基础（影响最深远的四大问题）

| 问题 | 理由 |
|------|------|
| **#8 黎曼猜想** | 素数分布核心、千禧年大奖难题、1000+ 条件定理的基石（见 [[concepts/学习/黎曼猜想]]） |
| **#2 算术相容性** | 哥德尔不完备定理直接由此催生，彻底改变了数学基础的面貌——"真理"与"可证性"不再相同 |
| **#10 丢番图可判定性** | Matiyasevich 否定解决 → 希尔伯特第十问题本身诞生了计算理论中"不可判定性"的范式，深刻影响了计算机科学 |
| **#1 连续统假设** | Cohen 力迫法（forcing）的发明直接改变了集合论——证明了 ZFC 的局限性，开辟了集合论多元宇宙的研究方向 |

### Tier 2：催生了整个数学分支

| 问题 | 理由 |
|------|------|
| **#9 互反律** | 类域论 → Langlands 纲领的源头，连接数论、表示论与调和分析 |
| **#12 克罗内克** | 虚二次域的类域论显式构造——至今仅有虚二次域和 Q（Kronecker-Weber）完全解决，推动 Langlands 纲领核心 |
| **#5 李群** | Gleason-Montgomery-Zippin 解决 → 奠定了李群理论的基础，广泛用于物理（规范理论）、几何 |
| **#7 超越性** | Gelfond-Schneider → 超越数论的支柱，后续 Baker 定理催生丢番图逼近 |

### Tier 3：高影响力且已解决

| 问题 | 理由 |
|------|------|
| **#17 Artin** | 实代数几何的基础定理，Hilbert 第十七问题与形式幂级数和优化理论深刻关联 |
| **#22 单值化** | Koebe-Poincaré 单值化定理 → 复分析核心工具，Riemann 曲面分类 |
| **#14 Nagata** | 否定解决反而推动了代数几何中的不变量理论与几何不变量理论（Mumford GIT） |
| **#19/20 PDE** | 变分问题解的正则性与边值问题 → 奠定了 PDE 理论的现代框架 |
| **#16 代数曲线/曲面拓扑** | 希尔伯特第十六问题前半已解决，但第二部分（极限环个数有限性）仍是动力系统最难的开放问题之一 |
| **#21 Riemann-Hilbert** | Deligne（1989）用 perverse sheaves 和 Hodge 理论解决所有正则奇点情形——连接了复分析、代数几何和微分方程 |

### Tier 4：影响较窄但各具价值

| 问题 | 理由 |
|------|------|
| **#18 Kepler** | Hales (1998) 用计算机辅助证明解决 Kepler 猜想，促进了形式化证明（Flyspeck 2014 完成形式化验证） |
| **#13 七次方程** | Kolmogorov-Arnold 表示定理：任意连续多元函数可表为单变量连续函数的有限叠加——与当下神经网络表示理论（万能逼近定理）有有趣呼应 |
| **#6 物理公理化** | 概率论（Kolmogorov）、经典力学与相对论已完成；量子场论与量子引力未完成——见 [[concepts/学习/希尔伯特第六问题]] |
| **#15 Schubert** | 舒伯特计数演算推动了枚举几何的发展，但严格基础化仍属部分解决 |
| **#3, #4, #11** | 各自解决了特定分支的技术问题，影响面不如上述各项广泛 |

## 解决机制分类：三种"解决"

希尔伯特 23 个问题的解决方式可分为三类，这一分类本身反映了数学发展的深刻特征：

1. **正面解决** — 给出希尔伯特预期的答案（如 #7 Gelfond-Schneider 证明超越性，如 #17 Artin 证明平方和表示）
2. **否定解决** — 证明希尔伯特的设想本身不成立（#3 Dehn 反例、#10 不可判定、#14 Nagata 反例）
3. **不可判定** — 证明问题在现有公理体系内既不能证明也不能证否（#1 连续统假设在 ZFC 中独立）

第三种"不可判定"本质上指向公理体系的局限性，与 #2（哥德尔不完备）形成深刻呼应——希尔伯特 23 个问题无意中预言了数学基础的自我局限性。

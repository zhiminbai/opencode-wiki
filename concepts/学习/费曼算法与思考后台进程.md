# 费曼算法与思考后台进程

> 源：[[sources/阅读/费曼的花园]] — Marginalia 博客（Viktor Löfgren, 2024）

## 费曼算法

Murray Gell-Mann 描述的费曼思考方法：

1. **写下问题**
2. **认真地思考**
3. **写下答案**

核心洞见：这并非"你得够聪明"的玩笑——思考和 LLM 推理在机制上是平行的：输入数据 → 后台处理 → 输出结果。

## 思考的后台进程模型

| 阶段  | 动作        | 说明                                      |
| --- | --------- | --------------------------------------- |
| 输入  | 向大脑灌入相关信息 | 收集所有你认为相关的信息，以最简单的方式写下来。组装问题本身就是核心工作    |
| 隔离  | 远离新的输入    | 停止继续灌数据，否则最先输入的内容会被挤出上下文窗口。关键动作：离开键盘    |
| 处理  | 等待后台进程解析  | 几小时到几天不等。突然获得对问题领域的洞察（不一定立刻有答案，但会有更深理解） |
| 输出  | 必须写下来     | 洞察转瞬即逝。写下来同时也是给大脑的反馈信号：路径正确，继续行进        |

## 与 LLM 推理的平行关系

作者直接指出，这个思考方式和给 LLM 写提示词是**直接的平行关系**：

- 输入相关信息 = Prompt
- 避免干扰信息 = 防止上下文污染
- 等待处理 = Generation
- 输出结果 = Response

## 个人实践案例

作者 2021 年的生活节奏完美复现了这个算法：
- 工作日：埋头工作，往脑子里填满相关信息
- 周末（不带电脑）：离开输入源
- 结果：每个周末结束时都有好几页新想法，下周实现

## 园艺隐喻

延伸自作者另一篇文章 [[sources/阅读/思维的园地]]：

> 你今天所想的内容，是你昨天所读的结果。

阅读不仅是内容的输入，更是**思维的模板**——同时包含"修剪"（剔除八卦和噪音）和"种植"（注入有趣有洞察的内容）。

# 南京房贷政策（2026年中）

> 含商业贷款和住房公积金贷款。政策截至 2026 年 7 月。

---

## 一、商业性个人住房贷款

### 1.1 利率基准

当前 LPR（2026年6月22日公布，最新）：
- **5年期以上 LPR：3.5%**
- 1年期 LPR：3.0%

> LPR 自 2025 年 6 月以来连续 13 个月保持不变。每月 20 日公布（遇节假日顺延）。

实际利率 = LPR + 商业银行加点。各银行首套/二套加点不同，需咨询。

### 1.2 首付比例

| 情况 | 最低首付比例 | 备注 |
|------|-------------|------|
| 首套房（普通） | **20%～30%** | 视银行审核 |
| 青年置业 "鑫青贷"（45岁以下） | **最低 15%** | 南京银行专项产品，详下 |
| 二套房（有1套且贷款未结清） | 历史政策约 45%～80% | 实际执行需咨询银行 |
| 商业用房（含商住两用房） | **≥ 30%** | 银发〔2026〕14号文落地 |

### 1.3 "鑫青贷" — 青年置业特色产品

南京银行推出，面向 **南京市45周岁以下新市民和青年人**。

| 特征 | 内容 |
|------|------|
| 首付比例 | **最低 15%**，支持人才房票抵扣 |
| 贷款利率 | 南京住房贷款最低利率 |
| 前5年还款 | 可定制本金归还，**每月最低还100元本金** |
| 贷款期限 | 最长 **30 年** |
| 贷款额度 | 最高 **房屋购置价 85%** |
| 审批时效 | 最快 24 小时审批放款 |
| 配套消费贷 | 最高 300 万元（家装、婚庆、旅游等） |
| 配套人才贷 | 最高 3000 万元（创业/办企业） |

### 1.4 "卖旧买新" 贴息

南京市2026年稳定房地产市场政策：

| 条件 | 内容 |
|------|------|
| 时间 | **2026-03-20 至 2026-12-31** 完成新房网签 |
| 贴息 | **贷款总金额的 1%** |
| 总资金 | 1 亿元，先申领先得，用完即止 |
| 申领截止 | 2029-12-31 |
| 要求 | 本人挂牌卖旧 + 按揭买新（新建商品住房） |
| 办理地点 | 主城六区 → 市房地产市场交易中心；其他区 → 房源所在区房产部门 |

## 二、住房公积金贷款

### 2.1 适用条件

- 在南京公积金中心**连续足额缴存满6个月**（含）以上
- 个人和单位账户为正常缴存状态
- 在南京市行政区域内购买全部产权自住住房

### 2.2 利率（2026年现行）

| 贷款类型 | 1-5年（含） | 5年以上 |
|----------|------------|---------|
| **首套** | **2.1%** | **2.6%** |
| **二套** | **2.525%** | **3.075%** |

> 对比商业贷款（5年期以上 LPR 3.5%，2026-06-22）：首套公积金利率低约 **0.9 个百分点**。

### 2.3 首付比例

- **首套/二套：最低 20%**
- 贷款额度不超过房屋总价的 80%

### 2.4 贷款额度

额度取以下三项的 **最低值**：

**① 最高限额：**

| 情形 | 单人最高 | 家庭最高（双人） |
|------|----------|-----------------|
| 普通 | **80 万元** | **100 万元** |
| 多子女家庭（2个以上未成年子女） | 96 万元（上浮20%） | 120 万元（上浮20%） |
| 青年人才房票购房 | **160 万元**（限额2倍） | **200 万元**（限额2倍） |

> 多子女家庭上浮不与高层次人才贷款政策叠加。

**② 还贷能力计算：**

> 月缴存额 ÷ 缴存比例 × 还贷能力系数（现行 0.5）× 12 × 实际可贷年限

- 实际可贷年限 = 距法定退休年龄的年限，最长 **30 年**
- 夫妻双方均缴存的，额度相加

**③ 房价比例限额：** 不超过房屋总价的 80%

### 2.5 贷款期限

- 最长 **30 年**
- 不超过借款人距法定退休年龄的年限

### 2.6 2026年4月新政亮点

#### 代际互助贷款（"全家桶"升级）

| 场景 | 说明 |
|------|------|
| 购房人缴存时间不足 | 父母/子女可作为 **共同借款人** 申请公积金贷款 |
| 可贷额度未达上限 | 共同借款人可补足额度差额 |
| 年满18周岁在校生购房 | 也可适用 |

- 最高额度：家庭最高 100 万元（符合多子女等条件可叠加上浮）
- 共同借款人条件：连续缴存满6个月、无未结清公积金贷款、未签订逐月还贷协议
- 共同借款人可提取公积金偿还该笔贷款（含委托逐月还贷）

#### 逐月还贷留存金额降低

| 调整项 | 原标准 | 现标准 |
|--------|--------|--------|
| 账户最低留存 | 月缴存额的 **12倍** | 月缴存额的 **6倍** |

- 存量用户：2026年5月1日系统自动调整
- 可办理一次**补充提取**：余额 - 月缴存额×6 的差额

#### 苏皖29城异地贷款互通

- 从原江苏全省 + 安徽4城（共17城）→ **苏皖两省29城全域互通**
- 安徽新增城市：合肥、蚌埠、淮南、安庆等12城
- 苏皖公积金缴存人在南京购房 → 可向南京公积金中心申请贷款
- 南京缴存人在安徽任一城市购房 → 按南京政策办理购房提取和还贷提取，**不受工作地、户籍地限制**

#### 现/退役军人支持

- 现役军人服役期间、退役后**6个月内** → 视同连续缴存
- 可作为主借款人申请，个人最高额度 **80 万元**
- 办理流程简化

## 三、组合贷款策略

南京支持 **公积金 + 商业组合贷款**。建议策略：

1. **优先足额使用公积金额度**（利率最低，家庭最高100万）
2. 超出部分用商业贷款补足
3. 如符合青年人才房票条件 → 公积金额度翻倍至200万，可覆盖大部分贷款
4. 如符合青年条件但无房票 → 考虑 "鑫青贷" 组合：公积金（低利率）+ 鑫青贷（低首付15%+前5年低月供）
5. **卖旧买新贴息** 与以上可叠加

### 还款金额参考（公积金贷款100万，30年）

| 利率 | 月供 | 总利息 |
|------|------|--------|
| 公积金首套 2.6% | ~**4,005 元** | ~**44.2 万** |
| 商业贷款 3.5%（LPR） | ~**4,490 元** | ~**61.6 万** |
| **每月节省** | **~485 元** | **~17.4 万** |

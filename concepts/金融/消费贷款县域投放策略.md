## 二、渠道渗透路径

```
社区/村委 ──→ 产业园/集聚区 ──→ 优质企业
    │                │                │
    ├ 网格化建档     ├ 批量获客       ├ 员工福利贷
    ├ 整村授信       ├ 产业场景嵌入   ├ 公积金/社保贷
    └ 村委推荐核额   └ 租金/设备分期  └ 高管信用贷
```

## 四、操作要点

| 环节        | 做法                                                 |
| :-------- | :------------------------------------------------- |
| **社区/村委** | 联合村委会建立"信用档案"，以土地流转数据/农业补贴/医保缴纳作为辅助授信依据，**先建档后放贷** |
| **产业园**   | 与园区管委会签框架协议，以社保/公积金缴纳基数定额度，**批量发卡、批量激活**           |
| **优质企业**  | 筛选规上企业、高新技术企业、纳税A级企业，推出"企业员工福利贷"（HR推送、工资代扣）        |
| **风险控制**  | 产业园内单户上限3张信用卡/5笔循环贷；村委推荐客户首笔≤3万元；还款节奏匹配产业周期        |

## 六、核心判断逻辑

| 因素    | 权重  | 说明                   |
| :---- | :-: | :------------------- |
| GDP规模 | 30% | 反映经济总量，>1500亿为T1门槛   |
| 人均收入  | 25% | 反映消费能力，>65000元为高消费市场 |
| 人口基数  | 15% | 市场容量，>100万为人口大县      |
| 产业集聚度 | 20% | 是否有产业集群支撑批量获客        |
| 政策配套  | 10% | 地方政府金融支持力度、征信基础设施    |
|       |     |                      |

- **T1**（苏南强县）：GDP>1500亿+人均收入>65000元，市场成熟但容量大，**立即布局**，主打产品分层和场景渗透
- **T2**（苏中+苏南潜力县）：GDP~1200-1500亿，制造业强，**1年内进场**，助贷合作快速获客
- **T3**（百强县中后段）：GDP~900-1100亿，人口大县但收入偏低，**1-2年培育**，侧重小额分散+产业场景结合
- **T4**（一般县域）：GDP~600-850亿，渗透率低，**2-3年逐步进入**，优先与本地农商行合作
- **T5**（苏北欠发达县域）：GDP<650亿，人均收入低，**3年以上观察**，待基础设施成熟

---

> **监管约束**：消费金融公司可全国展业无地域限制；地方法人银行须在本辖区开展，跨区域措施仅限消费金融公司或纯线上银行。助贷合作须严格名单制准入，参见 [[concepts/金融/消费贷款监管要求]] 第70-99条。
>
> **数据说明**：GDP和收入数据为2024-2025年估算值，引用须以江苏省统计局官方数据为准。

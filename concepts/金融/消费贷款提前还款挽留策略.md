# 消费贷款提前还款挽留策略

> 用户使用优惠券后申请提前还款时，通过弹窗提示优惠损失以挽留客户。本文整理市场案例并给出四套弹窗文案方案。

---

## 一、市场案例

### 案例1：京东金融 — "优惠券不退"争议

**来源**：黑猫投诉（2024-04）

用户使用优惠券借款后提前还款，系统要求退回优惠金额。用户投诉"诱导顾客使用优惠券，如果要提前还款却要退回优惠"。

**结论**：条款虽有约定，但用户认为入口未显著提示，属于"先诱导使用、后追回优惠"。

### 案例2：饿了么/淘宝借钱 — "领券锁定还款"纠纷

**来源**：黑猫投诉（2022-11）

还款页面跳出优惠券弹窗，用户点击领取后被告知"已领取优惠券，不能提前还款"。用户诉称"领取前没有任何提示，一旦领取退也退不了"。

**结论**：消费者权益争议，平台被指霸王条款。

### 案例3：法院判例 — "N天免息券"实为优惠券

**来源**：澎湃新闻（2025-03），上海某法院

借贷平台推出"N天免息券——提前结清失效"，附加规则"限分×期、×期可用，限等额本息还款方式，提前结清场景下券失效"。

**法院认定**：
1. 名为"免息券"实为"优惠券"，是合法营销手段
2. 若未对金融消费者充分提示说明，导致误解，相关条款**可能不被支持**
3. 平台须在用户使用前清晰告知提前还款的优惠损失后果

### 案例4：银行消费贷利率优惠券

**来源**：每日经济新闻（2025-05）

多家银行通过"优惠券"名义将消费贷利率降至3%以下，提前还款时优惠自动失效，借款人需补回贴息差额。有银行在提前还款页面弹窗展示"剩余期数利息优惠明细"，让用户直观看到损失。

### 案例5：美团借钱 — 挽留弹窗

**经验做法**：

提前还款时弹窗展示：
- 已享优惠金额（如"已为您节省XXX元利息"）
- 提前还款将放弃剩余期优惠（"剩余XX期优惠约XXX元将失效"）
- 推荐选项："继续用款，享剩余优惠"（主按钮）

```
│    │ 您当前使用的优惠        │      │
│    │                         │      │

│    │    已享优惠：¥186.50    │      │
│    │    剩余优惠：¥372.00    │      │
│    │                         │      │
│    │  ✓ 新客立减红包 ¥50    │      │
│    │    （提前还款需退回）   │      │
│    │                         │      │

│                                     │
```

**设计要点**：
- 主按钮用"省¥XXX"正向表述，非"损失"负面表述
- 次按钮"仍要提前还款"降低用户防御
- 左对齐明细清单，信息清晰

## 三、无券场景挽留策略

未用券或优惠券已失效时，挽留逻辑从"优惠损失"切换到"额度损失 + 再借成本"。

### 挽留角力点

| 角度 | 话术锚点 |
|:---|:---|
| **额度可能收回** | 提前还款后系统重新评估，额度可能调降或收回 |
| **再借需重审** | 再次借款需重新提交资料、查征信，耗时1-3天 |
| **利率不确定** | 下次借款利率以当时政策为准，可能高于当前 |
| **便利性丧失** | 循环额度"随借随还、按日计息"的优势消失 |
| **机会成本** | 当前额度是优质客户专属，清贷后不再保留 |

### 弹窗设计方案

```
┌─────────────────────────────────────┐
│   ℹ️ 提前还款前，请了解              │
│                                     │
│   一旦结清，您的以下权益将失效：     │
│                                     │
│   ┌─────────────────────────┐       │
│   │  ✓ 可用额度 ¥50,000     │       │
│   │    → 结清后可能被收回   │       │
│   │                         │       │
│   │  ✓ 随借随还 按日计息    │       │
│   │    → 再借需重新申请审核 │       │
│   │                         │       │
│   │  ✓ 当前利率 3.6%        │       │
│   │    → 下次以当时政策为准 │       │
│   └─────────────────────────┘       │
│                                     │
│   💡 保留额度不产生任何费用，        │
│   需要时随时支取，无需重新申请。      │
│                                     │
│       [保留额度，随时可用]           │
│       仍要提前还款                   │
│                                     │
└─────────────────────────────────────┘
```

### 简洁版

```
│   · 无需再次申请                    │
│   · 不影响征信查询次数              │
│   · 按日计息，不使用不收费          │
│                                      │

```

### A/B测试建议

| 版本        | 核心信息         | 预期效果       |
| :-------- | :----------- | :--------- |
| **额度损失**  | 额度可能收回、再借需重审 | 针对有续贷需求的用户 |
| **便捷性损失** | 保留额度随借随还     | 针对对流程敏感的用户 |
| **利率风险**  | 下次利率可能更高     | 针对利率敏感型用户  |
| **征信保护**  | 避免短期内征信多次被查  | 针对征信意识强的用户 |

## 四、弹窗规则建议

| 维度 | 建议 |
|:---|:---|
| **触发条件** | 用户点击"提前还款" → 检测优惠状态 → 有条件则弹优惠版，无条件则弹无券版 |
| **展示内容** | 优惠名称、已享金额、将损失金额、剩余期数（有券）；额度/利率/便利性损失（无券） |
| **CTA策略** | 主按钮 = "继续用款，省XX元"或"保留额度"（正向表述）；次按钮 = "仍要还款" |
| **A/B测试** | 损失清单型 vs 温和顾问型，观察留存率差异 |
| **合规底线** | 必须在**用户用券前及还款前双重提示**，否则条款可能被认定为无效格式条款 |

> 判例提示：上海法院在"免息券"案中明确，平台未有效提示说明 → 消费者主张格式条款不成为合同内容 → 平台可能败诉。**双重提示（用券时 + 还款时）是法律合规必需。**

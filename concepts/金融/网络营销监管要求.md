# 网络营销监管要求

> 聚焦 **《金融产品网络营销管理办法》**（2026-09-30 施行）及其相关法规体系。

---

## 一、《金融产品网络营销管理办法》核心框架

**八部门联合发布**（央行、工信部、市场监管总局、金融监管总局、证监会、知识产权局、网信办、外汇局），2026年9月30日起施行。

### 1.1 适用范围

- **金融机构**：经国务院或金融管理部门批准设立的所有金融机构（银行、保险、证券、基金、期货、信托等）
- **第三方互联网平台**：非金融机构自营的网站、APP 等，为金融产品网络营销提供服务的
- **地方金融组织**：由地方金融管理机构参照执行
- 覆盖的行为：金融机构自行开展的网络营销 + 委托第三方平台开展的网络营销

### 1.2 核心规则

| 主题 | 要求 |
|------|------|
| **委托关系** | 第三方平台须接受金融机构**依法委托**，不得超出委托范围 |
| **金融机构责任** | 金融机构对委托营销行为承担最终责任，不可通过外包转移责任 |
| **平台义务** | 不得擅自以金融机构名义开展营销，不得截留客户信息 |
| **内容审核** | 营销内容须真实、准确、完整，不得虚假或误导性宣传 |
| **风险提示** | 须充分提示产品风险，不得使用夸大、片面的表述 |

### 1.3 分业监管架构

| 监管机构 | 负责领域 |
|----------|----------|
| **中国人民银行** | 支付、征信、信用评级 |
| **金融监管总局** | 银行、保险 |
| **中国证监会** | 证券、基金、期货 |
| **国家外汇局** | 外汇 |
| **市场监管总局** | 广告监管、反垄断、反不正当竞争、互联网收费监管 |
| **网信办** | 网络安全、信息内容管理 |
| **工信部** | 电信业务许可 |

### 1.4 与消费贷款/助贷的关联

- 消费金融公司（持牌非银机构）开展网络营销适配本办法
- 助贷业务中，**平台运营机构**向借款人展示贷款产品信息，属于"第三方平台为金融产品网络营销提供服务"
- 结合 **《助贷新规》**（金规〔2025〕9号）：
  - 平台运营机构不得以任何形式向借款人收取息费 → 网络营销管理办法进一步禁止平台超出委托范围的营销行为
  - 披露要求叠加：年化贷款利率、增信服务费率、综合融资成本等 → 网络营销管理办法要求营销内容须真实、准确、完整
  - 两者构成"营销行为 + 放贷行为"双线监管

## 二、《互联网广告管理办法》要点（市场监管总局令第72号，2023-05-01施行）

### 2.1 适用范围
利用互联网**设计、制作、代理、发布**广告的所有活动。替代2016版《互联网广告管理暂行办法》。

### 2.2 核心要求

| 要求 | 具体内容 |
|------|----------|
| **可识别性** | 互联网广告应当具有可识别性，使消费者辨明其为广告（第九条） |
| **一键关闭** | 弹出广告须显著标明关闭标志，确保一键关闭（第十条） |
| **软文广告** | 通过知识介绍、体验分享等形式推销商品/服务，应当显著标明"广告" |
| **直播带货** | 直播间运营者、直播营销人员发布的直播内容构成商业广告的，应当履行广告代言人/发布者义务（第十九条） |
| **竞价排名** | 不得在搜索结果政务服务网站、网页、APP、公众号中插入竞价排名广告（第十七条） |
| **禁止变相审查广告** | 禁止以健康、养生知识等形式变相发布医疗、药品、保健食品等须审查广告（第八条） |
| **未成年人保护** | 不得在针对未成年人的网站、网页、APP 中发布医疗、药品、保健食品、医疗器械、化妆品、酒类、美容广告，以及不利于未成年人身心健康的广告 |
| **广告发布者认定** | 以**发布行为**为标准（不再要求"能够核对广告内容、决定广告发布"），与广播电视一致 |

### 2.3 各方责任

- **广告主**：对广告内容真实性负责
- **广告经营者**：建立承接登记、审核、档案管理制度
- **广告发布者**：查验广告证明文件，核对广告内容
- **互联网平台经营者**：记录保存信息、主动发现删除违法广告、建立投诉受理、配合监测调查

### 2.4 管辖规则
- 由**广告发布者所在地**市场监督管理部门管辖
- 广告代言人为自然人的：经纪服务机构所在地 / 户籍地 / 经常居住地

## 三、其他相关法规

### 3.1 《网络交易监督管理办法》（2021/2025修正）
- 自动展期/自动续费：须在**消费者接受服务前**和**自动续费日期前**以显著方式提示，并提供简便取消选项，不得收取不合理费用
- 平台经营者须保存平台内经营者身份信息、商品/服务信息、支付记录、物流快递等交易信息
- 平台须配合市场监督管理部门开展网络交易违法行为监测

### 3.2 《网络反不正当竞争暂行规定》（2024-09-01施行）
- 禁止刷单、刷评、虚假交易、误导性展示
- 禁止反向刷单（恶意差评竞争对手）
- 平台经营者须加强对平台内竞争行为的规范管理
- 发现违规须及时处置并保存记录（不少于三年），向监管部门报告

### 3.3 《直播电商监督管理办法》（2026-02-01施行）
- 市场监管总局 + 国家网信办联合发布
- 直播电商全链条监管：主播、直播间运营者、平台、商家各方责任

## 四、对消费贷款营销的实务提醒

结合你关注的助贷业务，网络营销监管落地时需关注：

1. **助贷平台的营销活动是否超出委托范围** → 平台做产品展示/利率比较/导流，须有金融机构的明确委托
2. **贷款利率披露是否满足"真实、准确、完整"** → 不能只展示低利率而隐藏综合融资成本
3. **增信服务费的展示** → 《助贷新规》禁止平台向借款人收费，但营销展示页面如何呈现给借款人仍需合规
4. **营销内容可识别性** → 通过软文、知识分享等形式变相推荐贷款产品，须标明"广告"
5. **算法推荐** → 如助贷平台通过算法向用户推荐贷款产品，适用互联网广告管理办法第十九条

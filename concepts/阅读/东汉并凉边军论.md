# 东汉并凉边军与帝国崩溃

## 定义

东汉政权崩溃的并凉边军论：羌乱百年 → 边军膨胀 + 军费无底洞 → 国库枯竭、税基崩溃 → 并凉边军脱离中央形成割据势力（董卓、马腾、韩遂）→ 边军入主洛阳 → 东汉名存实亡。

这一论点在近现代史学界是主流解释之一。谢伟杰《东汉的崩溃：西北边陲与帝国之缘边》（2023）对此做了最系统的专书论证。

## 连锁反应链

```
羌乱不断 → 边军膨胀 + 军费无底洞
         → 加重内地赋税
         → 农民破产，流民遍地
         → 黄巾起义（184年）
         → 朝廷设州牧统管军政（188年，刘焉建议）
         → 地方军阀坐大（董卓 = 凉州系，丁原/吕布 = 并州系）
         → 中央崩解
```

## 关键节点

### 1. 羌乱百年——财政黑洞

东汉中期起，凉州西羌持续叛乱。从安帝永初元年（107年）起，战火烧遍凉州、并州，一度打到三辅。

- 第一次大规模羌乱（14年）：耗费 **240亿钱**，国库打空
- 第二次大规模羌乱（7年）：再耗 **80余亿**
- 段颎残酷镇压后羌乱暂息，但并凉二州"遂至虚耗"，边民死亡不可胜数

### 2. 弃凉州之议——朝廷穷到壮士断腕

永初四年（110年），大将军邓骘在朝堂提议**放弃凉州**。他说："譬若衣败坏，一以相补，犹有所完，若不如此，将两无所保。"满朝公卿一致同意。

虞诩力排众议，陈三不可，指出放弃凉州 = 关中门户大开 = 帝陵暴露 = 函谷关以西不再是汉土。太尉张禹被说服，弃凉之议作罢。

但此议的提出本身，说明边疆消耗已到了帝国无法承受的地步。

### 3. 边军坐大——只知将领，不认朝廷

凉州长期打仗，催生了一支高度军事化的地方武力。"关西出将，关东出相"——朝廷精兵尽在凉州边军，中央禁军反而羸弱。

郑泰精确评估："**天下所畏者，无若并、凉之人与羌、胡义从。**"

董卓的军队正是在凉州打羌人练出来的精锐。汉灵帝临终诏命董卓去当并州牧，要求他将军队交给皇甫嵩。董卓上书："乞将之北州，效力边垂"——公然据兵不交，朝廷无计可施。

谢伟杰指出，凉州人在长期共处中形成了独立的"凉州人"地域认同，凉州精英与洛阳朝廷离心离德，甚至有人公开说"天下非复汉有"。

### 4. 董卓入洛——致命一击

中平六年（189年）何进召董卓入京诛宦官。凉州边军一到洛阳，中央禁军根本打不过。董卓废少帝、弑何太后、迁都长安，东汉朝廷沦为傀儡。

董卓死后，其凉州旧部李傕、郭汜继续割据。而凉州另一批军阀——马腾、韩遂——则长期盘踞西北，直到建安十九年（214年）才被曹操平定。凉州边军这个潘多拉魔盒，打开了就关不上。

## 补充：非唯一原因

并凉边军论有说服力，但不能说是唯一原因。同等重量的助推器还包括：

1. **土地兼并**：豪强吞并小农土地，税基被掏空
2. **党锢之祸**（166–184年）：宦官与士族互相清洗，文官系统精英断层
3. **皇权衰微**：后期皇帝多幼年即位、早死，外戚与宦官轮庄治国

四项叠加才是完整的"亡国套餐"。

## 与官渡之战袁绍失败的关联

袁绍据河北四州、拥兵十一万、粮草充足，理论上最有实力统一天下。但袁绍"外宽内忌，好谋无决"，犯了所有能犯的错误，被曹操以少胜多。袁绍的失败与并凉边军论形成有趣对比：前者是人祸（主将决策），后者是天命（结构性衰败）。

# 岳阳楼记

## 基本信息

- **作者**：范仲淹（989–1052），字希文，谥文正，苏州吴县人
- **创作时间**：北宋庆历六年（1046 年）九月十五日
- **创作地点**：邓州（范仲淹时贬居邓州，未亲临岳阳楼）
- **写作缘由**：应好友滕子京（滕宗谅，时谪守岳州巴陵郡）之邀，为重修岳阳楼而作
- **出处**：《范文正公集》

## 全文

> 庆历四年春，滕子京谪守巴陵郡。越明年，政通人和，百废具兴。乃重修岳阳楼，增其旧制，刻唐贤今人诗赋于其上。属予作文以记之。
>
> 予观夫巴陵胜状，在洞庭一湖。衔远山，吞长江，浩浩汤汤，横无际涯；朝晖夕阴，气象万千。此则岳阳楼之大观也，前人之述备矣。然则北通巫峡，南极潇湘，迁客骚人，多会于此，览物之情，得无异乎？
>
> 若夫淫雨霏霏，连月不开，阴风怒号，浊浪排空；日星隐曜，山岳潜形；商旅不行，樯倾楫摧；薄暮冥冥，虎啸猿啼。登斯楼也，则有去国怀乡，忧谗畏讥，满目萧然，感极而悲者矣。
>
> 至若春和景明，波澜不惊，上下天光，一碧万顷；沙鸥翔集，锦鳞游泳；岸芷汀兰，郁郁青青。而或长烟一空，皓月千里，浮光跃金，静影沉璧，渔歌互答，此乐何极！登斯楼也，则有心旷神怡，宠辱偕忘，把酒临风，其喜洋洋者矣。
>
> 嗟夫！予尝求古仁人之心，或异二者之为，何哉？不以物喜，不以己悲；居庙堂之高则忧其民；处江湖之远则忧其君。是进亦忧，退亦忧。然则何时而乐耶？其必曰「先天下之忧而忧，后天下之乐而乐」乎！噫！微斯人，吾谁与归？
>
> 时六年九月十五日。

## 结构解析

| 段落 | 内容 | 功能 |
|------|------|------|
| 第 1 段 | 作记缘由（滕子京重修岳阳楼）| 叙事起兴 |
| 第 2 段 | 洞庭湖全景（衔远山，吞长江）| 总写大观 |
| 第 3 段 | 淫雨悲情（去国怀乡，忧谗畏讥）| 以景写悲 |
| 第 4 段 | 春和喜悦（心旷神怡，宠辱偕忘）| 以景写喜 |
| 第 5 段 | 古仁人之心（先忧后乐）| 升华主旨 |

## 名句

- "**不以物喜，不以己悲**"——超越环境与际遇的内心定力
- "**居庙堂之高则忧其民；处江湖之远则忧其君**"——无论在朝在野，忧国忧民的初心不变
- "**先天下之忧而忧，后天下之乐而乐**"——全文灵魂，范仲淹一生的注脚

## 背景

- 范仲淹写此文时，正因"庆历新政"失败被贬邓州
- 滕子京亦被贬岳州，两人同处逆境
- 范仲淹并未亲临岳阳楼，仅凭滕子京所寄《洞庭晚秋图》及自身早年太湖洞庭印象而成文
- 这种"看图作文"却成千古绝唱，恰恰说明文章的力量在于思想高度，而非实地描写

## 范公堤与岳阳楼记的完整三角

范仲淹一生做了两件跨越时空的事——**修了一道堤，写了一篇文章**。

| | 范公堤（1024–1028） | 岳阳楼记（1046） |
|------|-------------------|-----------------|
| 身份 | 从八品盐仓监 | 贬居邓州的前参知政事 |
| 性质 | 水利工程 | 散文 |
| 核心精神 | 为民请命，实干利民 | 先忧后乐 |
| 时间线 | 范 30 多岁 | 范 50 多岁 |

**先忧后乐不是空话——范仲淹在海滩上先做到了，才在岳阳楼记里写了出来。**

### 滕子京参与范公堤

滕子京不仅是《岳阳楼记》的邀约人，更是范公堤修建的**直接参与者**。

- **时间**：宋仁宗天圣年间（1024–1028）
- **身份**：泰州军事判官（同年在泰州任职）
- **角色**：范仲淹主持筑堤，滕子京"主动加入，襄赞其事"

范仲淹晚年为滕子京撰写墓志铭（《天章阁待制滕君墓志铭》），亲笔记下了修堤中的关键一幕：

> "在泰日，予为盐官于郡下，见君职事外，孜孜聚书作文章，爱宾客。又与予同护海堰之役，遇大风至，即夕潮上，兵民惊逸，吏皆仓惶，不能止，**君独神色不变，缓谈其利害，众意乃定**。予始知君必非常之才而心爱焉。"

暴潮冲垮新堤、兵民惊恐逃散之时，滕子京是唯一保持镇定的人。范仲淹正是从这件事认定他是"非常之才"。

### 完整关系链

```
范仲淹 + 滕子京（1015 同年进士）
    │
    ├── 同修范公堤（1024–1028）
    │      └── 滕子京风暴中镇定，稳定军心
    │
    ├── 同戍西夏前线（1040–1043）
    │      └── 滕子京为范仲淹部下
    │
    └── 双双被贬 → 滕子京修岳阳楼（1045–1046）
           └── 邀范仲淹作记 → 《岳阳楼记》
```

修堤认识了滕子京的才干，岳阳楼成就了千古名篇。**一道堤、一座楼、一篇记，连接了两个人二十余年的君子之交。**

### 204 国道与范公堤

范公堤在清末至民国间被改造为**通榆公路**（204 国道前身），南起南通，北至盐城阜宁。南通路段的 204 国道，路面之下即当年范公堤遗址。今仅盐城大丰草堰镇保存约 3.5 公里堤段。
